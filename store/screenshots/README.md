# App Store ekran görüntüleri (tr)

iPhone "medium display" seti: 1206 × 2622, RGB (alfa yok). Yerel Supabase'deki demo verisiyle
iPhone 17 Pro simülatöründen alındı; kullanıcı adları ve hücreler kurgusaldır.

Sıra (ilk 3 aramada görünür): harita → akıllı rota → mahalle savaşı → kayıt → sezon → herkes için.

Yeniden üretmek: ham ekranları `01-map.png … 06-start.png` adlarıyla bir klasöre koy, sonra
`cd mobile && python3 scripts/store-screenshots.py <ham klasör> ../store/screenshots/tr`.
Başlık metinleri `mobile/scripts/store-screenshots.py` içindeki `SHOTS` listesinde.
